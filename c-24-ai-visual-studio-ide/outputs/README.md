# 紫藤 · C++ 学习工作台

面向 C++ 初学者的响应式前端 Demo，采用米白与紫色的学习工作台视觉，页面注明为学生个人项目。

## 打开

直接打开 `index.html`，无需安装依赖。

## 功能

- 学习总览、解题分析、练习库、错题本独立切换
- 代码理解、基础运行模拟、逐步分析、提示式对话
- 解析常见分号报错，并引导检查相关代码行
- 题目图片上传预览；可补充题目文字，选择提示、解题思路或复杂度分析
- 对累加求和、求最大值、质数、阶乘等常见题型提供前端演示模板
- 后置递增、整数除法、循环计数器练习
- 可点击右上角头像修改昵称，设置保存在浏览器 LocalStorage
- 错题标签保存在浏览器 LocalStorage，支持记录导出
- 明暗主题与移动端底部导航
- 扩大主工作区并提高常用文字字号，减少大屏无效留白

## 图片解题能力边界

此 Demo 没有接 OCR 服务或云端大模型。它能预览上传图片，但不会自动识别图片题目；需要手动粘贴题目文字。常见题型会由浏览器里的演示规则生成解题步骤，其他题目会提示补充信息，不代表已具备任意 C++ 题目的自动求解能力。接入 OCR 和模型服务后，才能实现从图片识题到开放式算法分析。
